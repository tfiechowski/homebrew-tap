# tfiechowski/homebrew-tap

Homebrew tap for [ClaudeBarLimit](https://github.com/tfiechowski/claude-bar-limit), an unofficial macOS menu-bar app that shows your Claude Code usage limits.

```sh
brew install --cask tfiechowski/tap/claude-bar-limit
```

The app is not Apple-notarized; Homebrew does not remove Gatekeeper prompts. See the app's README for first-launch steps.
